# Portfólio Pessoal

Sejam bem-vindos ao meu projeto de portfólio pessoal.

Este projeto foi desenvolvido para colocar em prática e testar meus conhecimentos em HTML e CSS. Futuramente, pretendo atualizá-lo e adicionar JavaScript, conforme avanço nos meus estudos.

## Sobre o projeto

O projeto possui 5 seções principais:

### Introdução
Uma breve apresentação sobre mim, acompanhada de uma barra de navegação.

### Sobre mim
Uma apresentação da minha trajetória, interesses e objetivos.

### Conhecimentos
Uma demonstração das principais tecnologias e conhecimentos que estou desenvolvendo.

### Projetos
Projetos que desenvolvi ao longo da minha jornada de estudos e programação.

### Contato
Minhas principais redes e formas de contato.

## Objetivo

Este é um projeto simples, mas tem como objetivo demonstrar minhas habilidades atuais e acompanhar minha evolução no desenvolvimento web.

O projeto continuará sendo atualizado conforme eu adquirir novos conhecimentos e desenvolver novos projetos.
